# 001-browser-shell 功能规格

> 模块编号: 001-browser-shell
> 状态: 待实现
> 最后更新: 2026-07-20

## 1. 模块概述

### 1.1 目的

在应用内提供一个全屏 ArtWeb 浏览器组件，实现 URL 输入、页面加载和浏览历史记录功能。

### 1.2 解决的问题

- 用户需要一个沉浸式、无干扰的全屏浏览器体验
- 用户希望应用记住上次访问的网页，无需重复输入 URL
- 用户需要一个简洁的 URL 输入交互方式

### 1.3 范围

**包含**:
- 全屏 WebView 浏览器组件
- 浮动按钮触发 URL 输入
- URL 本地持久化存储
- 启动时恢复上次浏览状态

**不包含**:
- 多标签页
- 书签/收藏
- 历史记录列表
- 下载管理

## 2. 用户故事

- 作为用户，我启动应用后看到全屏浏览器界面，没有被状态栏和导航栏遮挡，让我获得沉浸式浏览体验。
- 作为首次使用者，我打开应用看到空页面和 URL 输入框，可以输入网址开始浏览。
- 作为回头用户，我再次打开应用时自动加载上次访问的网页，无需重新输入 URL。
- 作为用户，我点击左下角的浮动按钮，展开 URL 输入框，输入新的网址即可导航到目标页面。
- 作为用户，我确认 URL 输入后输入框自动隐藏，浏览器全屏显示目标网页。

## 3. 功能需求

### 3.1 全屏浏览器

- FR-001-001: 应用 MUST 全屏显示 ArtWeb 浏览器组件，覆盖操作系统状态栏和导航栏
- FR-001-002: 浏览器组件 MUST 占据应用窗口的 100% 宽度和高度

### 3.2 URL 加载

- FR-001-003: 应用启动时 MUST 检查本地 Preferences 存储中是否有 `saved_url` 键
- FR-001-004: 存在已保存 URL 时，浏览器组件 MUST 加载该 URL
- FR-001-005: 不存在已保存 URL 时，浏览器组件 MUST 显示空白页面

### 3.3 URL 输入

- FR-001-006: 应用 MUST 在左下角显示一个浮动操作按钮
- FR-001-007: 点击浮动按钮后，应用 MUST 在底部展开 URL 输入框
- FR-001-008: 首次启动（无历史 URL）时，URL 输入框 MUST 默认显示

### 3.4 URL 导航

- FR-001-009: 用户输入 URL 并确认后，浏览器组件 MUST 导航到目标 URL
- FR-001-010: 导航开始后，URL 输入框 MUST 自动隐藏

### 3.5 URL 持久化

- FR-001-011: 用户输入的 URL MUST 保存到本地 Preferences 存储
- FR-001-012: 存储的数据 MUST 包含 URL 和保存时间戳

## 4. 关键实体

| 实体 | 描述 | 关键属性 |
|------|------|----------|
| URL 记录 | 用户访问的 URL | url (string), savedAt (timestamp) |
| 浏览器状态 | 组件运行时状态 | currentUrl, isLoading, showUrlInput |

## 5. 验收场景

### 场景 1: 首次启动

- Given: 应用首次安装启动，本地无 URL 记录
- When: 用户打开应用
- Then: 浏览器显示空白页 + 底部显示 URL 输入框

### 场景 2: 输入 URL 并浏览

- Given: 用户看到 URL 输入框
- When: 用户输入 `https://www.example.com` 并确认
- Then: 浏览器加载该网页，输入框隐藏，URL 保存到本地存储

### 场景 3: 再次启动恢复

- Given: 用户上次访问了 `https://www.example.com`，已保存到本地
- When: 用户关闭并重新打开应用
- Then: 浏览器自动加载 `https://www.example.com`，不显示 URL 输入框

### 场景 4: 切换 URL

- Given: 浏览器正在显示网页 A
- When: 用户点击浮动按钮 → 输入网页 B 的 URL → 确认
- Then: 浏览器加载网页 B，输入框隐藏，URL B 覆盖本地存储

## 6. 非功能需求

- NFR-001: 应用冷启动时间 SHOULD < 2 秒
- NFR-002: WebView 首屏渲染时间 SHOULD < 3 秒
- NFR-003: URL 持久化操作 SHOULD 不阻塞 UI 线程

## 7. 假设与约束

- ArtWeb 组件的 Web 内核由系统提供，无需额外配置
- 用户设备需连接网络才能加载网页
- 应用不需要 HTTPS 证书管理（浏览器内核处理）

## 8. 依赖

- 上游依赖: HarmonyOS SDK @kit.ArkUI (Web 组件), @kit.ArkData (preferences)
- 下游依赖: 无
