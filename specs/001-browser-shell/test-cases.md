# 001-browser-shell 测试用例

> 对应规格: [spec.md](./spec.md)
> 最后更新: 2026-07-20

## 测试用例清单

### TC-01: 首次启动 — 显示空页面和 URL 输入框

| 项目 | 内容 |
|------|------|
| 优先级 | 🔴 高 |
| 前置条件 | 应用首次安装，本地无 `saved_url` 记录 |
| 测试步骤 | 1. 清除应用数据 2. 启动应用 |
| 预期结果 | WebView 显示空白页；底部显示 URL 输入框；浮动按钮可见 |
| 测试类型 | 集成测试 (ohosTest) |

### TC-02: URL 输入并加载网页

| 项目 | 内容 |
|------|------|
| 优先级 | 🔴 高 |
| 前置条件 | 应用已启动，URL 输入框显示 |
| 测试步骤 | 1. 在输入框输入 `https://www.example.com` 2. 点击确认/回车 |
| 预期结果 | 浏览器开始加载 example.com；输入框隐藏；浮动按钮可见；URL 保存到本地 |
| 测试类型 | 集成测试 (ohosTest) |

### TC-03: 再次启动 — 恢复上次 URL

| 项目 | 内容 |
|------|------|
| 优先级 | 🔴 高 |
| 前置条件 | 上次使用已保存 URL `https://www.example.com` |
| 测试步骤 | 1. 关闭应用 2. 重新启动应用 |
| 预期结果 | WebView 自动加载 `https://www.example.com`；不显示 URL 输入框 |
| 测试类型 | 集成测试 (ohosTest) |

### TC-04: 浮动按钮触发 URL 输入

| 项目 | 内容 |
|------|------|
| 优先级 | 🔴 高 |
| 前置条件 | 应用已启动，浏览器正在显示网页 |
| 测试步骤 | 1. 点击左下角浮动按钮 |
| 预期结果 | 底部展开 URL 输入框（预填当前 URL） |
| 测试类型 | 集成测试 (ohosTest) |

### TC-05: 切换 URL 并覆盖存储

| 项目 | 内容 |
|------|------|
| 优先级 | 🟡 中 |
| 前置条件 | 应用上次保存了 URL A，当前显示 URL A |
| 测试步骤 | 1. 点击浮动按钮 2. 输入 URL B 3. 确认 |
| 预期结果 | 浏览器加载 URL B；本地存储更新为 URL B（覆盖 URL A） |
| 测试类型 | 集成测试 (ohosTest) |

### TC-06: 输入无效 URL

| 项目 | 内容 |
|------|------|
| 优先级 | 🟡 中 |
| 前置条件 | 应用已启动 |
| 测试步骤 | 1. 输入无效字符串（如 "not a url"） 2. 确认 |
| 预期结果 | 应用提示 URL 格式无效；不进行导航；不保存无效 URL |
| 测试类型 | 集成测试 (ohosTest) |

### TC-07: 全屏覆盖状态栏和导航栏

| 项目 | 内容 |
|------|------|
| 优先级 | 🔴 高 |
| 前置条件 | 应用已安装 |
| 测试步骤 | 1. 启动应用 2. 视觉检查 |
| 预期结果 | 系统状态栏不可见；系统导航栏不可见；应用内容占据全屏 |
| 测试类型 | 集成测试 / 视觉验证 |

### TC-08: URL 持久化读写（单元测试）

| 项目 | 内容 |
|------|------|
| 优先级 | 🟡 中 |
| 前置条件 | 测试环境 |
| 测试步骤 | 1. 写入 URL 到 preferences 2. 读取 preferences 3. 比较读写值 |
| 预期结果 | 读出的 URL 与写入一致；时间戳为正数 |
| 测试类型 | 单元测试 (LocalUnit) |
