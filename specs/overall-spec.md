# BrowserShell 整体规格文档

> 最后更新: 2026-07-20
> 版本: 1.0.0

## 1. 系统概述

### 1.1 系统定位

BrowserShell 是一个基于 HarmonyOS 的轻量级浏览器壳应用，在应用内提供一个全屏 WebView 浏览器组件，支持 URL 输入、页面加载和历史记录功能。

### 1.2 目标用户

需要在内嵌 WebView 中展示网页内容的 HarmonyOS 终端用户（手机、平板）。

### 1.3 核心价值

- 提供一个简洁、全屏的浏览器体验
- URL 输入便捷，支持历史记录快速访问
- 本地存储 URL 信息，启动时可恢复上次浏览状态

## 2. 核心能力

### 2.1 全屏浏览器

- 应用启动后全屏显示 WebView 浏览器组件
- 全屏特性：覆盖操作系统状态栏和底部导航栏
- 沉浸式浏览体验

### 2.2 URL 输入与导航

- 左下角浮动按钮触发 URL 输入框展开
- 输入 URL 后加载对应网页
- 输入完成后输入框自动隐藏

### 2.3 URL 持久化

- 用户输入的 URL 自动保存到本地存储
- 应用下次启动时自动加载上一次的 URL
- 本地无 URL 记录时显示空页面和 URL 输入框

### 2.4 首次启动引导

- 首次启动（本地无 URL 记录）时：
  - WebView 区域显示空白页
  - 底部显示 URL 输入框
  - 引导用户输入目标 URL

## 3. 用户故事

| ID | 角色 | 行为 | 价值 |
|----|------|------|------|
| US-001 | 用户 | 启动应用 | 看到全屏浏览器界面，覆盖状态栏和导航栏 |
| US-002 | 用户 | 首次启动 | 看到空页面并输入 URL 开始浏览 |
| US-003 | 用户 | 再次启动 | 自动加载上一次访问的 URL |
| US-004 | 用户 | 点击浮动按钮 | 展开 URL 输入框，输入新地址 |
| US-005 | 用户 | 确认 URL 输入 | 浏览器加载目标网页，输入框隐藏 |

## 4. 功能需求

### FR-001: 全屏显示
- 系统 MUST 全屏显示 ArtWeb 浏览器组件
- 系统 MUST 隐藏操作系统顶部状态栏
- 系统 MUST 隐藏操作系统底部导航栏

### FR-002: URL 加载
- 启动时 MUST 检查本地存储是否有已保存 URL
- 有 URL：浏览器组件 MUST 加载该 URL
- 无 URL：浏览器组件 MUST 显示空页面

### FR-003: URL 输入
- 系统 MUST 在左下角显示浮动操作按钮
- 点击按钮 MUST 展开 URL 输入框
- URL 输入框 MUST 位于屏幕下方

### FR-004: URL 导航
- 用户输入 URL 并确认后，浏览器 MUST 导航到目标 URL
- URL 输入框 MUST 在导航开始后自动隐藏

### FR-005: URL 持久化
- 用户输入的 URL MUST 保存到本地存储
- 应用重启后 MUST 能从本地存储读取并加载 URL

## 5. 非功能需求

| 类别 | 需求 | 指标 |
|------|------|------|
| 性能 | 应用冷启动加载 | < 2 秒 |
| 性能 | WebView 首屏渲染 | < 3 秒 |
| 兼容性 | 支持设备 | 手机、平板 (HarmonyOS 5.1+) |
| 可用性 | URL 历史恢复 | 可靠恢复上次浏览 URL |
| 国际化 | 界面语言 | 中文（简体） |

## 6. 系统边界

**包含**:
- ArtWeb 浏览器组件的全屏展示
- URL 输入与导航
- URL 本地持久化存储
- 浮动操作按钮

**不包含**:
- 多标签页管理
- 书签/收藏功能
- 浏览器历史记录列表
- 下载管理
- 用户认证
